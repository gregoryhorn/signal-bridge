## Decision

v0.7 look-and-feel uses **Void Tactical**: deep navy void surfaces, cyan scan accent, high-contrast entity colors, real tab strip chrome. This is the visual acceptance reference for shell, tabs, Pilot Intel, Settings density, and LAN theme export.

| Timestamps / status | Cascadia Mono / Consolas | 10px muted |

## Spacing scale

`4 / 8 / 12 / 16 / 24` (xs → xl). Prefer these over one-off padding.

## Signature UI behaviors (must match mockup)

1. Active tab: bold label + **cyan underline** with soft glow  
2. Unread: blue badge on inactive tabs  
3. Close × on closable tabs; overflow control when many channels  
4. **Pilot Intel** first-class in menu bar  
5. Status bar: live dot · LAN state · channel count · translate mode  
6. Optional translated subline indented with left border (when dual-line display)  
7. Subtle left feed “scan edge” optional; keep restrained  

## Out of scope for this theme

- Amber/gold accent as default (Mockup B rejected)  
- Light mode  
- Per-channel themes  

## Implementation note

Map these tokens into `sb_ui/theme.py` (or `sb_ui/theme/` package). No hard-coded hex outside theme modules. LAN viewer CSS variables export from the same tokens.
