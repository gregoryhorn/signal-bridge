# Phase 2.5: Remaining Dialog Migration Implementation Plan

> **For agentic workers:** Executed via Codex dispatches with per-task review (see the dispatch prompts at the end). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the four remaining hand-styled dialogs onto the `sb_ui` theme/components foundation, deleting their inline style literals, with zero behavior change (roadmap Phase 2.5: "consistency follow-through; no direct issue").

**Architecture:** Pure style-source migration inside `signal_bridge_gui.py`: every raw hex literal and ad-hoc widget kwarg group in the four dialogs is replaced by `sb_theme.COLORS[...]` tokens and `sb_theme.*_kw()` helpers (the same vocabulary the Settings Center and Help Center already use). No widget structure, geometry, binding, or callback changes.

**Tech Stack:** Python 3 stdlib (tkinter), existing `sb_ui/theme.py` helpers. No new files, no new tests (style-only; the 49-test suite guards regressions in shared modules).

Widget kwarg groups → helpers (replace the whole styling group with `**sb_theme.<helper>()`, keeping non-style kwargs like `text`, `command`, `width`, `wraplength`):

| Old pattern | Replacement |
|---|---|
| `tk.Button(..., bg="#1c2835", fg="#d7dde5", activebackground="#263544", activeforeground="#ffffff", relief="flat")` | `tk.Button(..., **sb_theme.btn_secondary_kw())` |
| Accent/primary buttons (`bg="#1f6feb"` family) | `**sb_theme.btn_primary_kw()` |
| `tk.Entry(..., bg="#070b10", fg="#d7dde5", insertbackground=..., relief="flat")` | `**sb_theme.entry_kw()` |
| `tk.Checkbutton`/`tk.Radiobutton` style groups | `**sb_theme.check_kw()` / `**sb_theme.radio_kw()` |
| `tk.Listbox` style groups | `**sb_theme.listbox_kw()` |
| `tk.Text` style groups | `**sb_theme.text_kw()` |
| `tk.OptionMenu` `.configure(...)` style groups | `.configure(**sb_theme.optionmenu_kw())` |

Notes:
- Normalizing `#1c2835`-family buttons to `btn_secondary_kw()` (bg `#111821`) is an INTENDED small visual change — it aligns dialog buttons with the Settings/Help/About windows.
- A literal with no row in the table and no obvious token: do NOT guess and do NOT silently keep it — finish the rest, keep that literal, and list it in your report as a deviation for the reviewer to decide.
- Font tuples like `("Segoe UI", 10, "bold")` → `sb_theme.font(10, bold=True)`.
