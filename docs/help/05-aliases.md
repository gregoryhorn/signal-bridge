# Aliases

Aliases map alternate spellings, abbreviations, and slang to the real
system or ship they mean, so recognition and highlighting still work.

## Managing aliases

- **Settings** menu, then **Aliases...** opens the alias editor.
- Each alias maps text seen in chat (for example a shorthand like `1dq`) to the catalog entry it should count as, scoped as ship or system.
- Bundled starter aliases ship with the app; your additions are stored locally and survive updates.

If a term is being recognized as the WRONG thing (rather than not at
all), see the Recognition Rules topic instead — rules exclude text,
aliases add mappings.
