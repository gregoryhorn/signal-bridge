# Channels

Signal Bridge tracks the EVE chat channels you choose and shows each as a tab.

## Adding channels

- **Channels** menu, then **Add / Open Channels...** lists channels found in your chatlog folder **and** channels you saved previously.
- Saved channels with no current log file stay listed as **tracking, waiting for log** so you do not have to re-add them after restart.
- **Settings > Channels** shows tracking counts and the same open/restore actions.

## Working with tabs

- The **All** tab shows every tracked channel combined.
- Unread indicators appear on inactive tabs when new lines arrive.
- Right-click a tab for actions: close it, close other channels, close all, copy the channel name, or restore hidden tabs.
- **Channels** then **Restore Hidden Tabs...** brings back tabs you closed.
- **Close All Active Channels** (also under Settings > Channels) stops tracking everything at once.

Closing a tab only hides it in Signal Bridge — it does not close the
channel in EVE or delete any log files.

## Live-only vs backlog

By default Start Monitoring is **live-only**: existing log content is not replayed.

Optional **startup backlog** (Settings > General): when enabled, recent lines within the last N minutes (default 10) are ingested once, then live monitoring continues.
