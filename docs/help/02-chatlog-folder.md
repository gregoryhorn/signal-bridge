# Chatlog Folder

EVE Online writes chat logs as text files while you play, with the
**Log Chat to File** option enabled in EVE's chat settings.

## Where Signal Bridge looks

Signal Bridge auto-detects the usual locations:

- `Documents\EVE\logs\Chatlogs`
- `OneDrive\Documents\EVE\logs\Chatlogs`

## Changing the folder

- Open **Settings**, page **General**, card **Folders**, button **Choose Chatlog Folder...**
- **Tools** then **Open Chatlog Folder** opens the current folder in Explorer so you can confirm files are appearing.

## Troubleshooting

- If the status bar reports a missing chatlog folder, EVE has not written any logs yet or the folder moved (OneDrive folder redirection is a common cause).
- New chat lines only appear for channels that are open in EVE and being logged.
