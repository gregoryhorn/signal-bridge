# Getting Started

Signal Bridge is a lightweight Windows app for live EVE Online chat
monitoring, CN <-> EN translation, and intel highlighting.

## First run

- Signal Bridge auto-detects your EVE chatlog folder (see the Chatlog Folder topic if it guessed wrong).
- Open **Channels** then **Add / Open Channels...** and pick the intel or chat channels to track.
- Use **File** then **Start Monitoring** to begin the live feed. Monitoring also starts automatically on launch.

## Reading the feed

Recognized text is highlighted by type:

- Systems: yellow
- Ships: red
- Non-ship assets and modules: purple
- ESS: light blue

Each tracked channel appears as a tab. The **All** tab shows the combined
feed. Unread indicators appear on inactive tabs. Right-click a message for
copy actions; right-click a pilot name for **Pilot Info**.

## Where things live

- **Settings** menu: all configuration pages (translation, appearance, aliases, ESI, exclusions...).
- **Tools** menu: diagnostics copy, logs folder, chatlog folder.
- **Help** menu: these topics, update check, and About Signal Bridge.

More documentation: https://github.com/gregoryhorn/signal-bridge
