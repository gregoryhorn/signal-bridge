# Pilot Info

Right-click a pilot name in the feed and choose Pilot Info to open the
pilot card.

## What the card shows

- **Summary**: report count, first/last seen, last system, ship, and status from your local sightings.
- **Recent Activity**: the latest local sightings.
- **Patterns**: top ships, statuses, signals, and systems for this pilot.
- **zKill**: cached 30-day kill/loss summary with threat priority, ISK destroyed/lost, ranked **Recent kills** (small-gang engagements first, large fleet as fallback) and **Recent losses**, each with a gang-size label (solo / small gang / fleet / large fleet) and a `zkill` link to the killmail.

## Actions

- **Copy**: copyable text summary of the pilot.
- **Flags**: manual flags (Watchlist, FC, Scout, Hot Dropper, threat levels...) with a note.
- **Activity**: full recent sightings list.
- **Sync zKill**: fetch a fresh zKillboard summary in the background. The card never blocks on network â€” it renders cached data only.
- **Open zKill**: the pilot's zKillboard page in your browser.
