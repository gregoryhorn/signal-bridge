# LAN Phone Viewer

Optional **read-only** live feed for a phone, tablet, or second PC on the same
local network.

## Enable

1. Open **Settings > LAN Viewer**.
2. Read the security note: anyone on your LAN with the URL can view the feed.
3. Turn on **Enable LAN phone viewer**.
4. **Copy URL** (or scan/type it on your phone).
5. Open the URL in a mobile browser on the same Wi‑Fi.

Use **Regenerate token** if the URL was shared by mistake. Use the toggle off
(or exit the app) to stop sharing.

## What you see

The phone page mirrors the desktop feed text and entity colors (systems, ships,
pilots, links) using the current Void Tactical theme. Use the channel filter on
the phone to focus one channel or All.

## What it does not do

- No remote control of Signal Bridge
- No access to settings, ESI tokens, logs, or cache files
- No internet relay — LAN only
