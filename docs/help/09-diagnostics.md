# Diagnostics

When something looks wrong, Signal Bridge can tell you what state it is in.

## Quick actions

- **Tools** then **Copy Diagnostics** puts a settings/state summary on the clipboard — paste this into an issue report.
- **Tools** then **Open Logs Folder** opens the app's log files.
- **Settings**, page **Diagnostics**, shows live counters and recent events.

## Reporting an issue

- **Help** then **Report an Issue...** opens the GitHub issue tracker: https://github.com/gregoryhorn/signal-bridge/issues
- Include: what you did, what you expected, what happened, the Copy Diagnostics output, and any relevant log lines.

Known issues and their status are tracked in ISSUES.md in the repository.
